Optional portfolio analytics

Updated 29 October 2026. Basic page opens are counted automatically without cookies or persistent browser/session IDs. Each document uses a random in-memory event ID solely to prevent duplicate retries. It is not reused across page loads. Detailed analytics start only after you select Allow. Declining does not affect the portfolio, resume downloads or demos. Your browser's Global Privacy Control or Do Not Track signal disables both automatic opens and optional detailed tracking.

What is recorded

With permission: page views, project and demo interactions, resume-download clicks, outbound link domains, coarse device category, referral category/domain, and visible activity time by section. Referral paths, search queries, URL parameters, chat content, form fields, names, email addresses, raw IP addresses and full browser user-agent strings are not stored by this analytics implementation.

Identifiers and timing

A random first-party browser ID lasts up to 30 days. The server stores a keyed hash of it; it is a pseudonymous identifier, not a person's identity. Sessions group activity across tabs until 30 minutes of inactivity. Approximate unique visitors means unique consented browser IDs, so different devices, cleared storage and private browsing can count separately. No fingerprint is generated.

Engaged time is estimated while the page is visible and focused and within 30 seconds of activity. Hidden or unfocused time does not count. Server-side time-range merging prevents duplicate retries and overlapping tabs from adding the same seconds twice. Elapsed session span is reported separately. These signals cannot prove someone read a page or completed a download.

Choice and storage

Your preference is kept for up to one year. Browser/session IDs and a bounded retry queue are stored only after permission; they are not the authoritative shared database. Use Analytics preferences in the footer to withdraw. Withdrawal stops future optional collection and removes local tracking IDs and queued events in this browser. Previously recorded aggregates are retained.

Retention and access

Detailed pseudonymous events and sessions are retained for up to 365 days after their last activity, subject to the configured daily retention job. Anonymous lifetime visit/page-view totals remain. The public counter shows recorded page opens from activation onward. Refreshing or opening another page can increment it; it does not count distinct people or sessions. Basic event IDs are retained for up to 365 days for deduplication and daily trends; numerical lifetime totals remain. Declining optional analytics leaves the basic identifier-free count active, unless a browser privacy signal disables it. The owner dashboard requires server-side authentication and provides aggregates, not individual visitor records.

Hosting services

When configured, Netlify runs the functions and managed PostgreSQL stores analytics. Hosting providers necessarily receive network information to serve requests and may retain their own operational logs under their policies. Application code does not store raw IP addresses; Netlify may transiently use IPs for rate limiting. Optional external project sites, embedded media or AI chat services have their own privacy practices.
