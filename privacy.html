Site information

This portfolio records a basic count of page visits and estimated elapsed time open. It does not use analytics cookies, persistent visitor identifiers, fingerprinting or cross-site tracking. No consent interface is used.

Each document has a temporary random event ID to merge its time updates and prevent retry duplicates. The application stores the ID, opening time and elapsed seconds in first-party PostgreSQL. It does not store names, emails, IP addresses, complete browser user agents, referrers, project clicks or download activity. The identifier is never reused for another page opening.

Counts include repeat openings and do not identify unique people. Time open includes idle/background time; heartbeat delivery and tab closure make it an estimate. Older visits without timing are excluded from averages.

Detailed visit records expire after 365 days; numerical lifetime counts remain. The report is protected by owner authentication. Hosting providers have their own operational logging practices.
